Model Segmentation

Sol · Terra · Luna 역할 및 업무 적합도

작업의 복잡도와 처리 빈도에 따른 명확한 티어 구분

👑

GPT-5.6 Sol

최상위 플래그십 ($5 / $30)
  • 복잡한 다단계 논리 추론
  • 고난도 코딩 및 디버깅
  • 전문 분석 보고서 / 법률 / 보안 검토
  • 장시간 자율 에이전트 실행
🎯 전략: 고도의 정확도가 필수적인 5~10% 핵심 업무에 선별 배치
⚖️

GPT-5.6 Terra

성능/비용 균형형 ($2 / $12)
  • 블로그 및 마케팅 콘텐츠 작성
  • 일반 업무 코딩 및 데이터 정리
  • 고객 상담 챗봇 본문 생성
  • 사내 지식 검색(RAG) 응답
🎯 전략: 단일 모델로 폭넓은 사내 업무를 커버할 때 최우선 검토
⚡

GPT-5.6 Luna

초고속 대량 처리 ($0.20 / $1.20)
  • 문장 분류, 태깅, 카테고리화
  • 단문 요약 및 키워드 추출
  • 대용량 문서 번역 및 전처리
  • 실시간 초저지연 응답 챗봇
🎯 전략: 수십만 번 반복 호출되는 80%+ 대량 파이프라인의 핵심

💡 모델 선택 시 주의점
1. 토큰 단가 ≠ 실제 총비용
모델마다 토큰 분할 방식(Tokenizer)과 캐싱 정책이 다르므로 실측이 필수입니다.
2. 정답률과 재작업 비용
단가가 저렴해도 오답으로 인해 재요청이 발생하면 총비용이 증가합니다.
3. 도구 연동(Tool Calling) 능력
외부 DB나 API 연동 시 정확한 파라미터 호출 성능을 검증해야 합니다.

Strategy & Action Plan

기업의 AX 최적화 도입 전략 (Hybrid Routing)

비용 78% 절감과 서비스 품질 극대화를 위한 실행 로드맵

🔄 3단계 지능형 라우팅 아키텍처
1단계: Luna 전진 배치 (80% 업무)
의도 분류, 키워드 추출, 1차 요약, FAQ 응답 → 초고속·초저비용 즉시 완료
2단계: Terra 본문 작성 (15% 업무)
일반 문서 작성, 코딩 보조, 복합 고객 상담 → 품질과 비용 균형
3단계: Sol 심층 검증 (5% 업무)
법률/보안 정밀 분석, 아키텍처 최종 승인 → 무결점 품질 확보
🎯 권장 실행 과제 (Action Items)
1. 사내 API 호출 현황 전수 조사

고가 모델(GPT-4/Sol)로 단순 처리 중인 작업을 선별해 Luna로 즉시 전환

2. 지능형 라우팅 게이트웨이 구축

프롬프트 복잡도에 따라 Luna/Terra/Sol로 자동 분기하는 미들웨어 적용

3. Task당 총비용 KPI 관리

단순 토큰 가격 대신 '업무 1건 완수당 실제 투입 비용'을 핵심 지표로 설정
